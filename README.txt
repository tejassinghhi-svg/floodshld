FloodShield — Day 2
======================
Features:
- Delhi interactive map
- Search any Delhi locality/road/sector/landmark using OpenStreetMap Nominatim
- Prototype risk score dashboard
- Rainfall, drainage, elevation and historical-risk factors
- Risk history chart
- Automatic critical-threshold detection
- Full-screen emergency flood warning
- Emergency siren-style Web Audio alarm
- Mute / acknowledge controls
- Flood-event simulation for SIH/demo presentation

Important:
This is a front-end prototype using illustrative/demo risk values. It is NOT a live flood-warning service.
Browser audio policies may require the user to click "Enable Alert Sound" or start the simulation before audible audio can play.
For a real deployment, Day 3 can connect the risk engine to live rainfall/weather, elevation, drainage and official flood-warning data.
